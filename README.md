# Formulário Staff BPV — versão pronta

Abra `index.html` no navegador ou publique os arquivos no GitHub Pages.

O envio já está configurado para encaminhar as candidaturas ao Discord. As respostas são separadas em mensagens organizadas para respeitar os limites de tamanho do Discord.

## Arquivos
- `index.html`: formulário
- `styles.css`: aparência e tamanhos das fontes
- `script.js`: etapas, validação, salvamento e envio
- `config.js`: configuração do webhook

## Aviso importante
O webhook está no `config.js`. Ao publicar em GitHub Pages, qualquer pessoa que inspecionar o código poderá encontrá-lo. Se isso acontecer, exclua o webhook no Discord e crie outro.
